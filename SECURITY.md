# Security policy

## Supported versions

Security fixes are applied to the latest revision of the `main` branch. There are no separately supported release branches yet.

## Reporting a vulnerability

Please use the repository's private vulnerability reporting flow under **Security → Advisories → Report a vulnerability**. Do not include credentials, OAuth tokens, private CAD data, or a working exploit in a public issue.

Include the affected component, impact, reproduction steps using disposable data, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
